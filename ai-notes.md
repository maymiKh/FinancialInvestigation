Chunking : in case of large data  AI split data in chunk
Embedding : convert data into vector representation : numeric respresentation of data = "text" => [0.1, 0.2, 0.3, ...]
Vector Database : store vector representation of data for fast retrieval and similarity search
Semantic Search : search based on meaning of the query rather than exact match
Tokenization : process of breaking down text
RAG : Retrieval-Augmented Generation, a method that combines retrieval of relevant documents with generation of responses
Context- window : the amount of text that can be processed at once by a model
